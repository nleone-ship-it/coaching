# 🏈 Drill Menu Builder

A React app for football coaches to create, organize, and print customized drill menus for their position groups.

## Features

- **Edit Mode**: Create and manage drill categories with custom colors
- **Category Management**: Add, delete, and reorder drill categories
- **Drill Organization**: Add, edit, and remove individual drills
- **Save/Load**: Export your menu as JSON and reload it anytime
- **Preview Mode**: See your drill menu formatted for printing
- **Print/PDF**: Generate a professional drill schedule with weekly planning grids

## Quick Start

### Prerequisites
- Node.js 16+
- npm

### Installation & Deployment

```bash
# 1. Clone the repository
git clone https://github.com/nleone-ship-it/coaching.git
cd coaching

# 2. Install dependencies
npm install

# 3. Test locally
npm run dev

# 4. Deploy to GitHub Pages
npm run deploy
```

Your app will be live at: **https://nleone-ship-it.github.io/coaching/**

## Usage

1. **Edit Your Details**: Enter your coach name and position group
2. **Manage Categories**: Add new categories or edit existing ones
3. **Add Drills**: List the drills for each category
4. **Choose Colors**: Select from preset colors or create custom ones
5. **Preview**: Switch to Preview mode to see the formatted output
6. **Save**: Export your work as JSON for backup or sharing
7. **Load**: Paste previously saved JSON to restore your menu
8. **Print**: Generate a printable drill schedule with practice grids

## Default Categories

- Agility Drills (Every Day Drill - EDD)
- Run Techniques & Run Reads (EDD)
- Tackling Drills (EDD)
- Specialties
- Pass Rush (EDD)
